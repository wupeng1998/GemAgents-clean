## 实现

- JobLedger 只枚举带主记录结构的 `<job_id>.json`，显式排除 `.contract.json` 与 `.config.json`；旧主记录仍可读取，损坏主记录通过 `corrupt_records()` 单独报告。
- 增加 `reserved → started/running/...` 合法状态迁移表。终态重复 cancel 返回原记录，不会复活作业；非法状态倒退会拒绝。
- 新增 `abort_reservation()`，在 spawn/register 失败后把预留明确关闭为 `failed`；`reconcile()` 会把没有注册 worker 的孤儿预留记录标记为 `reservation_orphaned`，避免永久阻塞同一合同的重试。
- 增加 20 个独立进程争抢同一合同的幂等提交测试，以及预留失败、孤儿收敛、PID 身份和恢复回归。
