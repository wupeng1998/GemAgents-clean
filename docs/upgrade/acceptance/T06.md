# T06 acceptance: package identity and reproducible environments

**Status: ACCEPTED**

The distribution and primary CLI are now `gemagents`; the import path remains
`GemAgents`. The previous `enzyagent` and `agent` commands are explicit migration
aliases. The Conda environment is named `gemagents` to avoid sharing an unrelated
project environment.

Dependencies are separated into core, metabolic, benchmark, status, MEMOTE and
development profiles. Core startup no longer imports COBRA. Missing metabolic
dependencies produce an install command instead of a raw import traceback.
`uv.lock` resolves every declared profile, and the exported runtime lock contains
package hashes. The container recipe pins the official Python 3.11.15 slim index
digest; this host has no Docker daemon, so no built image digest is claimed.

CI separates core, lightweight metabolic/SBML and manually requested MEMOTE jobs.
The MEMOTE adapter preserves raw reports and compatibility errors. PGAP remains a
separate documented runtime.
