The reconstruction run key includes normalized configuration, all input and
library contents, source policy, workflow code, solver package versions, numerical
settings and random seed state. Cache reuse verifies schema, contract key, original
status and hashes for every published artifact. Quality remains unchanged and
`reused` is a separate execution flag.

interrupted before cache publication resumes only artifact sealing after verifying
its identity and required outputs. The manifest records this resume lineage.
Atomic status and event indexes, best effort traceback capture and an OS execution
lease cover batch failure and duplicate submission. `--no-resume` provides the
full new attempt fallback.
