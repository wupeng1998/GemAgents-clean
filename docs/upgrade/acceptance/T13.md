# T13 acceptance: immutable model stages and export transactions

**Status: ACCEPTED**

Reconstruction stages are stored as immutable content-addressed artifacts under
`artifacts/stages/`: `initial`, `gapfilled`, `repaired` and `final`. Every artifact
records its semantic hash, file SHA-256, role (`raw`, `calibration` or
`exploratory`), parent artifact and attempt ID. The compatibility `draft.xml` and
`model.xml` files remain available, but retries no longer overwrite the immutable
stage lineage.

Quality feedback retries run under independent `attempts/NNNN/work` directories.
Patch records contain parent and before/after semantic hashes, reaction changes,
tasks and probes before/after, decision and reason. Attempt status is written
atomically. An accepted pointer is published only after a completed attempt passes
the required gate; a failed attempt leaves the previous pointer byte-for-byte
unchanged.

Every artifact is reloaded from SBML before publication and compared by normalized
semantic hash. Final artifacts reject audit probes. Raw and calibration-derived
models are kept as separate roles, and accepted metrics point to exact artifact IDs.
