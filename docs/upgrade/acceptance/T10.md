# T10 acceptance: evidence lattice and conservative GPR compilation

**Status: ACCEPTED**

Each structured evidence relation now records the input protein hash, function,
candidate reaction, annotation route, source class, database or model version,
thresholds, identity and coverage where applicable, ambiguity, complex status and
compartment support. Unknown values remain explicit instead of becoming negative
labels or invented confidence values.

The NCBI first and CLEAN fallback behavior remains the `legacy_v1` baseline.
`structured_v2` adds relation records and rejection reasons. CLEAN selection
fraction is recorded as a selection policy and is never emitted as a calibrated
probability. A probability field requires an independently identified calibration
label set.

The GPR compiler preserves complete AND complexes, keeps OR evidence branches
independent, separates reference protein matching from the original annotation
route, and rejects gapfill hypotheses. EC mappings with multiple reaction
candidates remain ambiguous and do not create substrate specific gene rules.

- Full repository suite: **235 passed, 0 failed**.
- Focused evidence, GPR, metabolic and semantic suite: **60 passed**.
- Frozen synthetic profile comparison: both policies produce 4/4 correct cases
  and 2/4 covered cases; structured output adds evidence without inflating GPRs.
- Ruff over `src`, `tests` and `scripts`: passed.
- `git diff --check`: passed.
