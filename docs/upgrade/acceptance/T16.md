# T16 acceptance: local candidates and shared multi-condition gap filling

**Status: ACCEPTED**

T16 keeps `weighted_lp` as the production baseline and adds an explicitly
bounded `shared_selection_bounded_v1` experiment. Candidate localization filters
evidence class, risk and local metabolite connectivity. Shared selection uses one
finite subset across all declared conditions, evaluates each condition on an
independent model copy and reports `SEARCH_INCOMPLETE` when the candidate cap is
hit. It does not claim a global optimum.

Negative phenotype checks maximize the biomass objective after applying each
condition medium; a zero-flux feasible solution therefore cannot satisfy a
negative-control maximum-growth bound. Rescue cost is budgeted and candidate
selection remains bounded by `max_selected`.
