# T03 acceptance: benchmark tracks and explicit mapping

**Status: ACCEPTED**

Mapping v2 binds assembly accession and version, strain evidence, sequence hash,
taxonomy evidence and model hashes. Ready rows explicitly name the selected
reference, biomass source and candidate references. Ambiguous or incomplete rows
remain `BLOCKED_MAPPING` in the denominator. Output names are content addressed,
so historical mappings are preserved.

The batch runner accepts only a validated `reference_assisted` mapping and records
actual candidate access and selected uses. It cannot claim sequence only use.
Reference order and workbook order do not select models implicitly.

Evidence:

- Schema: `schemas/benchmark-mapping.schema.json`.
- T03 regression command: **62 passed, 0 failed**. JUnit and stdout are under
  `artifacts/audit/T03/`.
- Track contract tests reject de novo access to reference support and inconsistent
  selected model declarations.

Rollback keeps v2 outputs and historical files, and disables their execution.
Legacy mappings remain ineligible for the benchmark runner.
