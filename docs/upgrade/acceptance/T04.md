# T04 acceptance: source policy and reaction evidence

**Status: ACCEPTED**

The default policy retains the MQC and external pear exclusions. Restricted paths,
including symlink targets, are blocked before hashing or deserialization. Source
records carry class, path, content SHA-256, acquisition time, usage terms,
authorization reference, derivation, allowed tracks and policy status.

Structured filtering isolates a restricted alternate source without deleting an
independent public record. Every exported reaction receives a stable `evidence_id`,
evidence class and source set. Solver selection is recorded separately and cannot
upgrade evidence. Unknown or blocked provenance yields `BLOCKED_PROVENANCE` rather
than a public claim.

Evidence:

- Policy: `data/source-policy.yaml`.
- T04 regression command: **68 passed, 0 failed**. JUnit and stdout are under
  `artifacts/audit/T04/`.
- Tests cover restricted alternates, false substring matches, symlink laundering,
  missing assets and complete reaction evidence IDs.
