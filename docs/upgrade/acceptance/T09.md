# T09 acceptance: chemical identity, equivalence and isolation

**Status: ACCEPTED**

Reaction library chemistry now has explicit entity identity, equation equivalence
and isolation contracts under `metabolic/library/`. Identity includes namespace,
accession, compartment and protonation convention. Aliases merge only when their
declared chemistry is compatible.

Canonical equation fingerprints preserve orientation and exact source scale, so
reverse equations and scaled equations can share chemistry without losing the
flux conversion. Different compartments and equations remain distinct.

Formula and charge changes use atomic `ChemistryPatch` records. Each record carries
old and new values, source, affected reaction closure, before and after static
checks, optional dynamic checks and a deterministic patch ID. A regression rolls
the model back. `scripts/replay_chemistry_patch.py` independently replays a patch
against its original SBML snapshot and verifies the recorded result.

Reaction QC records `strict`, `unknown_chemistry`, `imbalanced`,
`empirical_biomass` and `authorized_rescue` separately. Build output includes a
reaction evidence ledger, source versions or explicit unresolved values, source
hashes and a reproducible recipe.
