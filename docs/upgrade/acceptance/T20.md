# T20 acceptance: fair benchmark metrics and uncertainty

**Status: ACCEPTED**

T20 adds frozen-protocol evaluation utilities that keep engineering failures,
unknown phenotype labels and execution time separate. Growth labels use an
explicit threshold; unknown labels and timeout/infeasible observations are
excluded from the phenotype denominator and counted separately. Pairing
requires identical sample, medium hash, biomass, protocol hash and evaluation
track. Cluster bootstrap resamples strain groups rather than model versions.

Reaction overlap now has a chemistry and compartment equivalence path, and gene
overlap requires an explicit orthology/accession map. Reference-assisted
evidence is explicitly excluded from de novo accuracy. The existing comparison
script no longer strips E. coli-specific REF prefixes or treats b-locus prefixes
as a universal gene mapping.

The frozen dataset is still insufficient for biological claims. The benchmark
runner therefore emits separate engineering, consistency, experiment and cost
sections with status insufficient_data and retains all failure fields. No
default algorithm upgrade is claimed.
