# T17 acceptance: semantic cache and performance profiling

**Status: ACCEPTED**

T17 separates rebuild, annotation and audit-certificate cache namespaces and
derives audit keys from order-independent LP structure, custom constraints,
variable types, probe, closure, numerical strategy and solver semantics. Audit
PASS reuse remains monotonic: only a model whose current variable bounds are a
subset of the bounds used for the cached PASS can inherit it. FAIL witnesses
are never stored as reusable evidence. `cache=False` still runs the complete
uncached verifier.

`PerformanceProfiler` records stage, cache state and metadata, then reports
paired medians and ranges. The offline benchmark records cold, hot and
uncached audit timings in `artifacts/audit/T17/performance.json`; these are
execution measurements and are not model-quality claims.

Evidence:

- Full repository suite: **276 passed, 0 failed**.
- Focused cache and profiler suite: **5 passed**.
- Ruff over `src`, `tests` and `scripts`: passed.
- `git diff --check`: passed.
- Offline paired benchmark: 3 cold, 3 hot and 3 uncached samples, with medians
  and ranges recorded separately.
- Concurrent audit regression confirms probe reactions do not enter caller
  models and solver/model state is not shared between runs.
