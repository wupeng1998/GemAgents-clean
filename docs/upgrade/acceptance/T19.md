# T19 acceptance: budgeted evidence escalation experiment

**Status: ACCEPTED (EXPERIMENTAL_NOT_PROMOTED)**

T19 adds immutable EvidenceRequest and EvidenceResult records for five
deterministically diagnosed gap types. Requests are idempotent and finite;
adapters must be explicitly authorized, match a declared source version and
return structured citations. Empty results, unauthorized sources, incomplete
citations and budget exhaustion are recorded as rejected or not-found states.
An approved result creates a candidate EvidenceRevision with
rebuild_required=true; it never edits a model or GPR directly.

The benchmark compares no-evidence, fixed-order and selective strategies under
the same synthetic budget. Fixed-order and selective tie on this fixture, so
there is no evidence to promote selective acquisition to the default path.
The deterministic core remains the rollback/default behavior.
