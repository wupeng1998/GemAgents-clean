# T18 acceptance: contract-driven routing and recoverable jobs

**Status: ACCEPTED**

Reconstruction requests now pass through a deterministic ReconstructionContract
before metabolic_start can spawn a worker. The contract records input identity
and type, organism domain, annotation route, evaluation track, medium/biomass
declarations, budgets, required QC and external access. FAA inputs route to
ncbi-hmm; raw FNA cannot route to full PGAP through the FAA path, and
unsupported eukaryotic FNA requests are blocked. Missing assets are rejected
before a job directory is created.

ToolSpec records parameter and artifact schemas, prerequisites, permissions,
side effects, budgets and failure types. The persistent JobLedger stores
contract_id, job_id, attempt_id, process-start identity, heartbeat, checkpoint,
cancellation state and content identity. Recovery refuses changed
configuration bytes and rotates the attempt ID. Status checks compare the
recorded process-start identity, so a reused PID cannot be treated as the
original worker. Deterministic routing and the metabolic CLI do not require an
LLM.
