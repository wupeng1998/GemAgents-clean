# T15 acceptance: local multi-direction repair search

**Status: ACCEPTED**

`metabolic/qc/repair_search.py` adds an experimental, local and finite hitting-set
search. Each witness contributes signed reaction directions; every selected patch
must hit every witness, and a caller may reject candidates that fail protected
physiological tasks or an independent audit. Protected reactions block the search
with `blocked_by_protected_evidence`. Search limits return `SEARCH_INCOMPLETE`,
never a global-unsatisfiable claim.

The existing `repair` implementation remains the production `current_greedy`
behavior. The new search is not silently enabled, and its ablation directory
requires reporting covered violations, task preservation, edit cost and search
budget before any default change.
